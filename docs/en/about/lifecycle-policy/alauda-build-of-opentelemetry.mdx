# Alauda Build of OpenTelemetry v2 Lifecycle Policy

## Version Lifecycle Timeline

Below is the life cycle schedule for released versions of the `Alauda Build of OpenTelemetry v2` operator:

| Version  | Release Date  | End of Support  |
| -------- | ------------- | --------------- |
| v2.0.z   | 2026-04-21    | 2027-10-21      |

## Release Policy

A new version of the `Alauda Build of OpenTelemetry v2` operator is released every 4 months.

## Maintenance Policy

Alauda provides 18 months of maintenance support for each released version of the `Alauda Build of OpenTelemetry v2` operator.

During the maintenance period, Alauda will provide the following services to customers:

1. Track the patch versions and promptly provide patches containing bug fixes and security updates.
2. Provide security updates that comply with Alauda's security standards.
3. Assist customers in smoothly upgrading the operator to new versions.
