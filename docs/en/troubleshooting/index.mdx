# Troubleshooting

Alauda Container Platform Application Observability provides multiple approaches to diagnose and resolve issues with the OpenTelemetry Collector and its instrumentation components. This documentation covers common troubleshooting scenarios, including log collection, metrics exposure, debugging tools, and network policy configuration.

These troubleshooting methods enable you to effectively monitor the Collector's operational status, investigate data collection issues, and ensure proper transmission and processing of telemetry data.
